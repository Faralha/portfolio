## Overview
HMTC (Himpunan Mahasiswa Teknik Computer-Informatika) is the Informatics student organization at ITS. In 2026 I serve as **Head of the IT Development bureau**, a role close to project manager: I set the technical direction, organize the team, and own how everything gets shipped.

I stayed on after my first year as a frontend staff member (see [HMTC 2025 Website](/projects/web-development/hmtc-2025)). This year I took over the repositories left by the previous cabinet and consolidated them, then built the infrastructure that runs them.

## What I Did
- Consolidated repositories inherited from the previous cabinet into one maintained set.
- Built the deployment setup with **Caddy** and **Docker Compose**, with separate staging and production environments and basic authentication in front of staging.
- Automated CI/CD with **GitHub Actions** and **GHCR**.
- Provisioned servers and backups with **Ansible** playbooks and **Restic**.
- Set up a **Docmost** knowledge base so the next cabinet does not start from zero.
- Led the 2026 website, including a Directus CMS integration: [HMTC Website 2026](/projects/web-development/hmtc-frontend-2026).

## Tech Stack
Docker Compose, Caddy, Ansible, Restic, GitHub Actions, GHCR, Docmost

Status: ongoing.
